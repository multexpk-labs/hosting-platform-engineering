# Monitoring & Observability

Monitor both platform health and customer-service health.

## Signals

- Provisioning latency
- API error rates
- Queue depth
- Worker failures
- Provider API latency
- CPU/memory/storage capacity
- Network availability
- Service uptime
- Billing/provisioning reconciliation failures

## Method

`Detect → Correlate → Diagnose → Mitigate → Verify → Document`

Every automated action should produce enough structured evidence to explain what happened.
